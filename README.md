#### 🛒 [Deal Agent](https://github.com/adnan098raza/deal-agent)
An autonomous shopping-deal agent for Germany. It collects deals from deal communities, price comparators and shop pages, checks how trustworthy each seller is, and has an LLM score every deal. Results go out as ntfy digests 4× a day, an end-of-day email and a live Excel log.
`Python` `SQLite` `Groq / Gemini` `ntfy` `GitHub Actions`

#### 🎙️ [Creator Knowledge AI](https://github.com/adnan098raza/Creator-knowledge-ai.)
Turns a creator's YouTube videos and podcasts into a searchable knowledge base. Answers come from RAG, with transcript evidence and clickable timestamps.
`FastAPI` `React + Vite` `PostgreSQL` `Qdrant` `Groq`

#### 🌐 [WebLingo](https://github.com/adnan098raza/web-lingo)
A Chrome extension that auto-translates the sites you pick. Translation runs fully on your device through Chrome's built-in Translator API, with no API key and no server.
`TypeScript` `Chrome Extension MV3`

#### 📦 Idle Inventory Agent *(private, course project)*
Finds idle stock in SAP HANA Cloud and has an LLM draft clearance recommendations.
`SAP HANA Cloud` `Python` `Gemini` `Cloud Foundry`
